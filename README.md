- [Netlify](https://www.netlify.com/) - Netlify is a platform for deploying modern web projects with continuous deployment from Git. - [Scaleway](https://www.scaleway.com/) - Scaleway is a European cloud provider offering serverless containers, functions, and managed databases. - [Vercel](https://vercel.com/) - Vercel is a cloud platform for frontend developers to deploy static sites and serverless functions. ## Self-Hosted PaaS

- [CapRover](https://caprover.com/) - CapRover is an open-source, self-hosted PaaS that simplifies deploying apps on your own server. It features a web GUI, one-click apps, and Docker-based deployment. It is free to use and install on any VPS. ([Read more](/details/caprover.md)) `Open Source` `Self-Hosted` `Free Plan` `Docker` `GUI`
- [Cloudron](https://cloudron.io/) - Cloudron is a self-hosted platform for installing and managing web applications on your own server. It provides an app store, automatic updates, and user management. Pricing is paid for production use with a free tier for personal use. ([Read more](/details/cloudron.md)) `Self-Hosted` `Paid` `Free Plan` `App Store` `Docker` `Freemium`
- [Coolify](https://coolify.io/) - Coolify is an open-source, self-hosted Heroku alternative for deploying applications and databases. It runs on your own infrastructure and supports Docker, Git deployments, and SSL management. The software is free to use and self-hosted. ([Read more](/details/coolify.md)) `Open Source` `Self-Hosted` `Free Plan` `Docker` `Git`
- [Dokku](https://dokku.com/) - Dokku is an open-source, self-hosted PaaS that runs on a single server and uses Docker containers. It provides a Heroku-like experience via Git push commands and plugin support. It is free to install and use on your own infrastructure. ([Read more](/details/dokku.md)) `Open Source` `Self-Hosted` `Free Plan` `Docker` `Git`
- [Dokploy](https://dokploy.com/) - Dokploy is an open-source, self-hosted alternative to PaaS platforms like Heroku and Netlify.
